# Frontend - Angular
This directory contains the Angular frontend application.

## Structure
- `src/app/` - Angular application
  - `components/` - Angular components (Department, Employee)
  - `services/` - HTTP services
  - `models/` - TypeScript interfaces
  - `app.component.*` - Root component
- `src/` - Public files and styles
- `angular.json` - Angular configuration
- `package.json` - NPM dependencies

## Setup & Run
```bash
cd frontend
npm install
npm start
```

Application runs on: http://localhost:4200

## Key Features
- Standalone components (Angular 17+)
- Reactive forms
- HTTP client
- CORS enabled
- Responsive design
